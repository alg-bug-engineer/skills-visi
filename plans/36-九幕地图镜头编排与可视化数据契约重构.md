# 计划 36 · 九幕地图镜头编排与可视化数据契约重构

> 对应需求：`needs/36-九幕地图镜头编排与可视化数据契约重构.md`
> 分支：`feature/frontend-map-act-visualization`
> 状态：已完成；未合入 `main`

## 一、实施原则

1. 前端仅消费后端或 fixture 明确提供的几何；不按方向/长度合成业务几何。
2. Case A 缺失字段先查 PostgreSQL 实数并写入 fixture；Mock 只作为数据库无记录/无相应关系字段时的最后手段。
3. Mock 载荷必须携带 `mock:true` 与 `source:mock_visualization`，并在地图持续告警。
4. act 推进由统一 barrier 控制，禁止用固定 dwell 代替真实完成信号。
5. 覆盖物按层 diff；本轮先保证镜头、标注、barrier 的确定性，再逐步替换旧绘制器。
6. 不调整现有九幕叙事、顺序和文案；`references/3d源码` 仅作为渲染经验与参数源。

## 二、设计

### 2.1 演出状态

在 presentation store 增加：

```ts
type ActBarrierKind = 'typing' | 'voice' | 'map'
type ActBarrierState = Record<ActBarrierKind, boolean>
```

- act 切换时初始化当前 act barrier。
- ProcessPanel 完成打字后标记 `typing`。
- 语音 watcher 对该 act 的 cue 等待 `whenIdle()` 后标记 `voice`；语音关闭或无模板立即完成。
- AMapProvider 等待 `applyScene()`（含 beats）后标记 `map`。
- `tryAdvance()` 在三项未完成时只记录 pending；任一 barrier 完成后重新尝试推进。
- 每项完成提交 `runKey + actIndex`，旧 run/旧 act 回调直接丢弃。

### 2.2 地图分拍

新增 `config/mapChoreography.ts`：

- 定义每个 act 的 camera duration、overlay beat delays 和 reduced-motion 行为。
- `applyScene` 在主镜头完成约 60% 后可开始主标记；首阶段先采用镜头完成后短分拍，避免大范围重构竞态。
- 每幕总地图时长由真实 Promise 决定，不以旁白字数估算。
- 重构 AMapProvider 为“政务驾驶舱舞台”：深蓝黑地图、四周暗角与扫描光；删除地图 ACT 报幕，避免与右侧流程重复。
- MapController 每幕按 base → subject → evidence → conclusion 四拍揭示；节点/文本使用 stagger reveal，路径使用 glow/main/particle 三层。
- 流向溯源幕复用 3D 源码的 48° 高位斜俯视和青色光路；恢复 coverage 优先、sniff 仅缺失回退，单色路径前缀只蔓延一次，不创建附加粒子 marker。
- 溯源定框只纳入目标 2km 内真实拓扑，避免远端证据把镜头拉成全市缩略图；远端路径仍保留渲染。
- UI 卡片/按钮统一收敛到 1–2px 小倒角，以细角标、单向阴影和边框层级替代消费级大圆角与胶囊造型。

### 2.3 标注布局

新增 `map/labelLayout.ts`：

- 纯函数 `layoutLabels(specs, viewport, obstacles)`；输入屏幕锚点、估算宽高、优先级。
- 输出像素 offset、hidden/cluster 状态。
- 固定标签结构：主标题最多 1 行，副标题最多 2 行，数值使用 tabular nums。
- 地图绘制前通过 `lngLatToContainer` 获取锚点，再布局；resize/zoomend 重新排版。

### 2.4 数据拉取与 Mock 警告

- 从 fixture 提取 Case A 的 `inter_id/link_id/line_id/day_of_week/step_index`；指标使用 `traffic-metrics/scripts/query_metric.py`，路网几何按 `road6 version_id='20260501'` 查询。
- 指标依次核对 `queue_length/green_utilization/turn_saturation/turn_flow/link_speed/intersection_evaluation`，几何核对进口道、转向、停止线、上下游连接与协调路径。
- 实数写回 fixture 时附 `data_lineage`；后端 scene builder 输出相同字段结构。
- 新增 `MapDataWarning`，从当前 scene 递归检查 `mock/source`。
- `AMapProvider` 显示地图顶部橙色警告，不随标注淡出。
- fixture 仅为缺失字段补 `visualization_contract`，生产 API 不读取 fixture。

### 2.5 后端契约

- `act_map_enrichment.py` 所有 act scene 无论 available 与否均输出，带 `reason/missing_fields/source`。
- `plan_preview` 改从最终 `plan.recommended` 生成，并增加一致性状态；若与 action package/trial loop 冲突则 `available:false`。
- 扩展 cause/compare/control scene 的真实可推导字段；不可推导几何明确列入 `missing_fields`。

- choreography：九幕均有配置；Act 7 hold；reduced-motion 立即完成。
