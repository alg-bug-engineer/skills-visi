## 二、数据流（目标）

```
diagnosis_ticket.period / time_range
  → resolve_timing_period(schedule_cfg, day_of_week)
  → { target_periods, period_plan_no, step_index.. }
  → prepare_signal_for_ticket(pg_raw)  # 切换 plan + 重绑 turn_flow
  → build_optimizer_request(target_periods, planNo)
  → optimize → timing.meta（含时段元数据，无 virtual_flow 字段）
  → PlanEvidencePanel / StageCards / DirectionIntensityPanel
```
