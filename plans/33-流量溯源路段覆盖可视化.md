### 1.2 前端消费优先级

`MapController.drawTrace`：

1. 若 `flow_trace_segment_coverage_map.available` → `renderSegmentCoverage`
2. 否则降级提示「暂无数据」（**不再**默认走 sniff / legacy 合成路径作为生产呈现）

`collectTraceBoundsPoints`：纳入 coverage 的 link `coords` 与 intersection `lng/lat`。

### 1.3 票面映射

| 诊断字段 | 覆盖请求 |
|----------|----------|
| `target_inter_id` | `inter_id` |
| `dir8_code` 0..7 | `approach_leg`：`0→N_IN` … `7→NW_IN`（与参考 `APPROACH_LABELS` / 本仓 `DIR8_ENTRY` 对齐） |
| `turn_dir_no` | `turn_dir_no` |
| act5 来向 | `direction=upstream` |
| `period_type` / 票面时段 | 落到 parquet **实际日期** + `DEFAULT_PERIOD_WINDOWS`（早 07–09 / 晚 16–19 / 平峰 10–16） |

映射失败或窗口内零事件 → `available:false`，禁止跨日虚增。
