对应需求：`needs/23-流量溯源进口道转向约束复刻.md`
分支：`20260708210700-23-流量溯源进口道转向约束复刻`

## 一、设计总览

后端只改 `app/trace/map_scene.py::build_flow_trace_links_sniff_map_scene` 及其内部
辅助函数，使 payload 对齐 `references/流量溯源/source/backend/services/correlate_sniff_map_service.py`
的三条口径：**进口道+转向行级约束 → 多跳走廊 peer → 每路口完整 link 十字**。
前端 `renderSniffScene`（已按参考实现）保持不变，仅消费更完整的 `intersections/links`。

数据来源不变：`pg_raw` = `{trace_geometry, flow_correlate, channelization, peer_link_geometry?}`；
peer 几何走既有 `_fetch_peer_link_geometry()` live PG 取数（缺 `peer_link_geometry` 时）。

## 二、后端改动（`app/trace/map_scene.py`）

### 2.1 correlate 行级约束（新增）

新增走廊判定，等价参考 `incoming_row_in_corridor` / `outgoing_row_in_corridor`：

```
def _row_in_corridor(dir8, turn, trace_direction, row) -> bool:
    cor_d8 = int(row.cor_f_dir8_no); cor_turn = int(row.cor_turn_dir_no)
    if turn == 2:                      # 直行：同进口道直行来/去向
        return cor_d8 == dir8 and cor_turn == 2
    # 左/右/掉头：保留同进口直行锚点 + 非进口直行的转向走廊，交由拓扑一跳定序
    ...
```

### 2.2 `_correlate_peers` 重写（上游分支）

- upstream/downstream 统一：先按 `period_type` + `trace_type` + `f_dir8==dir8` + `turn` 过滤，
  再用 `_row_in_corridor` 约束，聚合出 peer（每 peer 取占比最大行，记录 `cor_f_dir8_no/cor_turn_dir_no`）。
- **移除 upstream 的跨转向求和**（旧逻辑把所有 cor 行 sum 到一个 peer，语义错）。
- 结果按占比降序；`in_main_corridor = (cor_f_dir8==dir8 and cor_turn==2)`。

### 2.3 每路口完整 link 十字

- **target**：直接用 `raw_target_links`（其全部进/出口 link），删除 `_filter_turn_links` 裁剪。
- **peer**：用 `peer_geometry[inter_id]["links"]` 全集，删除 `_filter_turn_links` 裁剪。
- 保留 `parse_linestring_wkt` 校验（`len(path) >= 2`）。

### 2.4 删除单一上游塌缩

- 删除 `_select_primary_upstream` 调用与 `suppressed_secondary_upstream` 塌缩逻辑；
  改为保留全部可见 peer（`_peer_visible`）。
- 可见性：`in_main_corridor` / `is_topo_anchor` 恒显示；其余按 `path_coverage >= MIN_PATH_COVERAGE(10)`。
  与参考 SNIFF_MIN_COVERAGE=0 的差异以 `stats.hidden_non_main` 显式记录（避免噪点，同时保留主走廊全量）。

### 2.5 拓扑一跳锚点

- 沿用 `topo.upstream_nodes/downstream_nodes` 首个作为 `is_topo_anchor` 与 `main_order`。
- `main_corridor_chain` 由 `in_main_corridor` peer 按占比/hop 排序生成。

### 2.6 定向

- 完整十字场景下，每条 link 用自身真实 WKT，不再统一 `orient_path`（避免把十字掰直）。
- 仅无 peer 几何、退回 `relation_direction` 邻接 link 的兜底路径保留 `orient_path`。
