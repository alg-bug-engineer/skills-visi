## 二、数据契约（目标）

`POST /api/v1/agent/skill/solidify`
请求：`{ trace_id, plan_id, diagnosis_ticket?, plan_snapshot?, strategy?, artifacts_summary? }`（前端从 store 取真实快照透传）。
响应 `SkillSolidificationResult`：
```
{
  action: 'created' | 'updated' | 'unchanged',
  skill_id: string,
  skill_dir: string,            // 相对仓库根
  download_url: string,         // /api/v1/agent/skills/{skill_id}/download
  intersection: string | null,
  inter_id: string | null,
  time_period_label: string | null,
  tags: { match:{...}, content:{...}, meta:{...} },   // 来自真实 ticket/strategy/plan
  absorption: {
    action: 'CREATE'|'UPDATE'|'UNCHANGED',
    stages: [ { key, label, monologue, evidence_chips:[{key,label,value}], duration_ms } ],  // 6 阶段真实证据
    value_snapshot: { what:{title,bullets[]}, why_rows:[{key,label,before,after}], delta_rows:[] }
  },
  build: {
    stages: [ { key, label, progress } ],   // 7 阶段
    files: [ { path, name, language, content } ]   // 真实文件内容：SKILL.md/reference.md/scripts/*/skill.meta.json
  }
}
```
落盘目录：`data/skills/skill-{inter_id|slug}-{period|all}/`，文件：`SKILL.md`、`skill.meta.json`、`reference.md`、`scripts/fetch_traffic_data.sql`。upsert 依据目录键；内容签名相同 → `unchanged`，存在但变化 → `updated`，否则 `created`。

前端状态机 `solidifyPhase`：`idle → prompt →（decline: idle+reset）/（confirm: absorbing → building → completed → finish: idle+reset）`。

### 步骤 1（后端）：技能固化服务 + 真实落盘
文件：`app/services/skill_solidification_service.py`、`app/config.py`
- `SkillSolidificationService.solidify(ticket, plan_snapshot, strategy, ...)`：
  - 由真实 `diagnosis_ticket`（inter_id/intersection_name/period/direction/movement/problem_type/constraints）、`strategy`（principles/recommended/hard_constraints）、`plan`（recommended timing/expected_effect/rollback）派生技能内容；缺失显式降级。

## 七、风险
1. **技能内容真实性**：严格来源真实 ticket/strategy/plan，缺失降级不编造（遵 `docs/rule.md`）。
2. **动画时序**：分阶段 timer 需在 `webdriver`/`prefers-reduced-motion` 下即时完成，保证单测可断言终态。
3. **落盘副作用**：测试用 tmp 目录（`skills_output_path` 可注入），避免污染仓库 `data/skills/`。
4. **zip 下载**：流式返回，注意路径穿越校验（仅允许 `data/skills/` 下已存在目录）。
5. **既有 accept 行为变更**：确保退回/重置/mock 模式不回归，补充回归用例。
