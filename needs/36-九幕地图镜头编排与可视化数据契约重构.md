# 需求 36 · 九幕地图镜头编排与可视化数据契约重构

> 分支：`feature/frontend-map-act-visualization`
> 状态：已完成（Case A 浏览器验收通过）
> 参考项目：`/Users/zhangqilai/shensi/code/古特代码仓库/signalControl_agent-ui-design-opt`
> 最终地图视觉/动作参数源：`references/3d源码`

## 背景

当前九幕已具备基础运镜、渠化、下游拓扑、溯源和策略图层，但仍存在四类演示与生产问题：

1. 地图标注独立创建，缺少统一布局与避让，多文本标记会互相遮挡。
2. 幕推进只等待打字与语音；地图 `applyScene` 不参与 barrier，慢镜头可能跨幕。
3. `applyScene` 每次全量 `clear()`，SSE 同幕补数也会造成图层闪断。
4. Case A 的若干镜头缺少真实呈现字段，且 `plan_preview` 与最终动作包存在周期差异。

## 目标

### G1 · 九幕镜头编排

- 幕序严格保持当前叙事不变：对象识别 → 空间定位 → 证据核验 → 下游承接 → 流向溯源 → 归因分析 → 案例校验 → 策略边界 → 方案交付。
- 重度复用参考项目的色彩和地图语言：
  - 蓝 `#1a7fff`：识别/选中；青绿 `#00d4b4`：运行/流向；橙 `#f5a623`：预警/控流；
  - 红 `#ff4757`：异常；绿 `#2ed573`：保护/通过；紫 `#a8a0f8`：推理中。
- 多节点场景使用真实对象 `fitBounds`，按左右栏和底部抽屉计算安全区；溯源镜头只以目标 2km 范围内节点定框，范围外真实证据仍渲染但不拉远镜头。
- 案例校验幕保持镜头，不为动作而动作。

### G1.1 · 官员汇报级视觉重构（非原构图修补）

- 当前构图、HUD 位置和 marker 样式均可推翻；目标是“城市级信控驾驶舱”，不是开发调试地图。
- 叙事逻辑、九幕顺序、证据顺序与右侧文案保持不变；`references/3d源码` 只提供特效、配色、动作、镜头与渲染经验。
- 地图逐值复用 3D 源码参数：背景 `#030812`、雾/暗面 `#061225`、上下文路网 `#214a66`、主次道路 `#5ccfff/#2189ff`、交通四级 `#39dfff/#ffd247/#ff8d1f/#ff3c1f`。
- 流量溯源只使用原始 coverage 点位与路段；路径统一为青色 `#39dfff`，采用一次性 `path_prefix` 逐段蔓延，不叠加 sniff 路网、不创建动画粒子点、不循环闪烁。
- 目标节点采用固定屏幕圆点与呼吸/涟漪；删除会被误读为纺锤体的垂直光柱；卡片采用深色玻璃标签。
- 每幕覆盖物按“底图/真几何 → 主对象 → 证据/关系 → 结论标签”分拍揭示，并以柔和缩放、淡入和扫描光衔接。
- 地图保留运行态光点、暗角与扫描层；删除地图上的 `Act X` 报幕胶囊，幕信息只在右侧流程区表达。
- 主 UI 由大圆角/胶囊式卡片收敛为 1–2px 小倒角、细角标和方向性阴影，保持政务驾驶舱的硬朗结构；不改变信息层级与 Act 9 尺寸。

### G2 · 三栅栏同步

每个 act 建立三项完成状态：

- `typing`：右侧打字机完成；
- `voice`：该幕语音 cue 播放完成或语音关闭；
- `map`：该幕镜头与分拍覆盖物完成。

仅当三项均完成且下一 phase 已就绪时，才允许进入下一 act。重放、跳幕、reset 必须使旧 token 失效，禁止旧异步动作穿透到新幕。

### G3 · 标注避让

- 所有地图文本标记进入统一布局器；按屏幕像素空间检测重叠。
- 候选方位按 `上 → 右 → 下 → 左 → 四角` 搜索；高优先级标注先布局。
- 无法无重叠放置时，聚合为 `+N`，点击展开；禁止直接覆盖。
- 连线标签优先放在线段中点外法线方向，路口标签使用双环节点上方。
- 标注最大宽度、行数和数字排版统一；长文本省略并由点击展开。

### G4 · 数据库实数优先与 Mock 可视化安全

- 先按 Case A 的对象标识、星期与 5 分钟时间窗直接查询济南 PostgreSQL：指标走 DWS，路网几何走 `road6` 当前生产版本。
- 数据库已有的数据必须回填 Case A fixture，并保留 `source/table/identifier/time_window` 等血缘；fixture 是前端验收基准，后端目标契约必须与之对齐。
- 只有数据库不存在、无法由真实关系表解析的数据，才允许在 fixture 中补充 `source: mock_visualization`、`mock: true` 的临时演示载荷。
- 任何消费 mock 呈现字段的地图必须显示持续可见的橙色警告：`演示模拟图层 · 生产待补数据`。
- 生产响应禁止前端合成或静默 fallback 到 mock；字段缺失必须 `available:false + reason + missing_fields`。
