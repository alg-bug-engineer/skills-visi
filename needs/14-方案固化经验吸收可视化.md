# 需求14：方案下发后「经验吸收 + 技能固化」可视化闭环

分支：`20260708115448-14-方案固化经验吸收可视化`
参考：`references/frontend-v2`（技能固化/经验吸收权威实现）、`references/流量溯源/docs`（流程规格 D1/D2、SSE 阶段规格）；仅借鉴，禁止 import/提交参考代码。

## 一、背景与目标

当前项目方案（治理建议）在 `PlanDrawer` 点击「接受并下发」后，`store.accept()` 记录反馈（`POST /agent/plan/decision`）随即 `reset(true)` 直接回到主页，缺少参考项目中「方案下发 → 经验吸收 → 技能固化」的可视化闭环。

目标：将参考项目 `references/frontend-v2` 中「方案生成后的技能固化 + 经验吸收 + 固化可视化」逻辑移植到当前项目，形成如下闭环：

1. **下发后弹窗**：方案下发成功后，弹出「技能固化」确认弹窗（参考 D2 `确认固化 / 暂不固化` 语义）。
2. **不固化分支**：点击「暂不固化」→ 直接返回主页（等价当前 `reset(true)`）。
3. **固化分支**：点击「确认固化」→ 进入
   - **经验吸收（可视化）**：按 `recap→decompose→retrieve→compare→value→blueprint` 6 阶段呈现（终端式逐字流 + 证据 chips + 吸收前后价值对照表）。
   - **技能固化（可视化）**：按 `understanding→planning→writing_skill_md→writing_reference→writing_scripts→writing_meta→packaging` 7 阶段呈现（阶段时间线 + 文件树逐个生成 + 代码逐字写入 + 进度百分比）。
4. **完成态**：固化完成后展示技能卡片摘要（技能 ID / 路口 / 时段 / 命中标签）+「下载技能包」+「返回主页」按钮。

## 二、真实性约束（遵 `docs/rule.md` 禁编造）

- 固化必须产生**真实产物**：后端把本次已采纳的诊断/策略/方案真实落盘为一个 Agent-Skill 包（`SKILL.md` + `skill.meta.json` + `reference.md` + `scripts/`），内容全部来源于本轮真实 `diagnosis_ticket / strategy / plan`；缺失字段显式降级，不虚构指标。
- 可视化的「阶段/逐字/文件树」是**呈现层动画**，其数据（证据 chips、价值对照、文件内容、技能标签）均来自后端真实返回；不允许前端凭空编造技能内容。
- 若后端不可用或 mock 模式：前端以 mock 返回驱动动画，并在文案标注为演示数据（与既有 `VITE_MOCK` 一致），不冒充生产落盘。

## 三、架构决策

- **不新增第二套 SSE 基建**：参考项目通过 SSE 逐帧推流固化过程。为降低风险、保证一致体验，本需求采用「单次 `POST /agent/skill/solidify` 返回结构化真实结果 + 前端分阶段动画」的方式：后端一次性完成真实落盘并返回吸收证据 + 构建文件（含真实路径/语言/内容）+ 技能元信息；前端按阶段节奏（尊重 `prefers-reduced-motion` / webdriver 即时）逐步呈现。
- **技能固化=真实落盘**：后端写入 `data/skills/skill-{inter_id}-{period}/`，按目录键 upsert，返回 `action ∈ created/updated/unchanged`。
- **前端插入点**：在 `store.accept()` 记录反馈后，不立即 `reset`，改为进入固化提示态；由新的全屏覆盖组件按 `solidifyPhase` 状态机呈现弹窗/吸收/构建/完成。

## 四、验收标准

1. 方案下发后必现「技能固化」弹窗；「暂不固化」返回主页，会话重置。
2. 「确认固化」后依次呈现经验吸收 6 阶段与技能固化 7 阶段动画，数据来自后端真实返回。
3. 后端真实写出技能包目录与文件；重复固化同键为 `updated/unchanged`，不重复堆叠。
4. 完成态展示技能卡片 + 下载 + 返回主页；返回主页后可开始新一轮诊断。
5. 后端 `pytest -q` 全绿新增用例；前端 `npm test` + `npm run build` 全绿新增用例。
6. 既有接受/退回/重置行为不回归（`presentation-reset` / `presentation-closure` 等仍通过）。

## 五、非目标

- 不实现参考项目完整「技能排行榜/命中计数/复用快路径 D1」链路（仅完成态可展示技能卡片摘要，排行榜可后续排期）。
- 不改动地图图层、方案生成配时链路、需求 12/13 成果。
- 不实现运行时把技能重新注册进 pipeline 执行（固化产物为可下载/可检索资产）。
