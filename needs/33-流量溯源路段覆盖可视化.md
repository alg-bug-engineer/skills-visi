# 需求 33 · 流量溯源改为「按路段覆盖」可视化

> **状态：待开发**  
> 分支：`20260713110534-33-流量溯源路段覆盖可视化`  
> 参考（只读，禁止 import / 禁止提交）：`references/sequence_restore_custom_h0610/`  
> 对应计划：`plans/33-流量溯源路段覆盖可视化.md`

## 一、背景

现有 act5 流量溯源地图消费 `map_scenes.flow_trace_links_sniff_map`：基于 `flow_correlate` 聚合 peer，在每个路口画完整 link「十字」发光链（需求 7/9/23）。

参考项目 `sequence_restore_custom_h0610` 使用恢复轨迹序列（`inter_sequence_with_time.parquet` + `restored_trips.parquet`），按 **rid 路段**聚合流量占比，在地图上以 **路段覆盖 Polyline（线宽∝ratio）+ 来源路口圆点** 呈现上下游溯源。该口径更贴近「走廊覆盖」叙事，需替换当前 sniff 十字可视化。

## 二、约束（对齐 `docs/rule.md`）

- **数据真源**：路段/路口几何来自 PG（`dim_inter_info`、`dim_rid_trace_info`/`dim_rid_info`）；流量占比来自恢复轨迹 parquet 聚合。无数据 → `available:false` + `reason`，禁止合成（约束 14/16/19）。
- **references**：只可拷贝/借鉴逻辑，禁止 `import references`，禁止把参考目录或大体积 parquet 提交进 git（约束 11）。
- **前端只呈现**：不得用标量在客户端造折线/坐标；缺字段则降级「暂无数据」。
- **生产化先写计划**：本文件 + `plans/33` 落地后再实施；改口径同步改单测（约束 4/18）。
- **剧本字段**：act5 所需结构化地图字段须在 Skill/`map_scenes` 中有定义（约束 17）。

## 六、验收标准

- **AC-1** 配置有效 parquet + PG 时，act5 地图可见按 ratio 变宽的路段覆盖与来源路口圆点，目标路口高亮。
- **AC-2** 后端 payload 含真实 `coords`/`lng,lat`/`ratio`/`flow`；低于 5% 的路口/路段不出现。
- **AC-3** 缺 parquet / 零事件 / 映射失败 → `available:false` + `reason`，前端「暂无数据」，无合成几何。
- **AC-4** 相关单测覆盖：映射、空数据降级、聚合占比、离群过滤、前端消费新键。
- **AC-5** 分支开发完成，**禁止直接合入 main**（约束 1）。
