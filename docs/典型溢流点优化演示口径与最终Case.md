# 典型溢流点优化演示口径与最终 Case

## 演示目标

在现有真实数据并不完整、不同指标日型覆盖不完全一致的条件下，优先形成一条可审计、可解释、可生成配时方案的典型溢流路口演示链路。所有指标均来自真实 PG，不补造数值。

## 数据选择口径

1. 目标进口转向：在周一至周日相同演示时间窗中，选择 `queue_len_avg` 峰值最大的日型，用于证明目标存在排队溢流风险。
2. 下游接收进口转向：合并周一至周日相同时间窗的有效样本，以排队均值评价常态承接能力；同时披露跨周峰值及峰值比作为安全审计，避免均值掩盖偶发风险。
3. 现状配时：优先加载目标峰值日覆盖演示时段的方案、调度时段和阶段映射。
4. 流量：优先使用目标峰值日同一时间窗的真实转向流量；缺失转向由优化器按现状放行比例和最小绿约束形成可追溯的降级输入，并在方案说明中披露。
5. 成案门槛：目标峰值排队比不低于 0.8；下游均值排队比低于 0.8，且下游峰值风险必须披露；存在可解析现状配时；方案生成完成并通过护栏。

## 指定干线筛选结果

严格排队候选中，花园东路与奥体中路、坤顺路自交等路口虽然目标和下游指标满足，但没有完整现状配时，不能作为最终方案生成演示。解放东路与齐川路同时具备目标溢流、下游空间和现状信号方案，因此作为最终 Case A。
