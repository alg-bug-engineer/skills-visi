# 点/线优化峰值口径演示说明

> 状态：演示阶段临时口径  
> 生效日期：2026-07-13  
> 适用范围：基于现有真实数据的点优化、线优化案例讲解

## 1. 为什么采用峰值口径

当前真实交通数据在路口覆盖、日期完整性、转向排队连续性和上下游同时段覆盖方面仍然有限。如果同时要求排队峰值、时段均值、P95 和持续切片数均达到生产级阈值，很难找到拓扑关系、目标转向和上下游指标都完整的演示路口。

现阶段演示的主要目标是说明完整决策逻辑：

1. 目标转向是否在窗口内出现明显供需失衡；
2. 该转向对应的直接下游是否具备承接空间；
3. 下游可承接时采用点优化，下游受阻时升级为线优化。

因此暂时采用“窗口峰值触发、上下游峰值保守校核”的方式保留真实数据案例。

## 2. 当前判定规则

目标路口在晚高峰窗口内满足任一条件，即认为存在优化问题：

- 排队比峰值 `>= 0.8`；
- 饱和度峰值 `>= 0.9`；
- 饱和度峰值 `>= 0.8` 且绿灯利用率峰值 `>= 0.85`。

随后按目标转向的出口拓扑检查直接下游：

- 下游排队比峰值 `< 0.8` 且下游饱和度峰值 `< 0.85`：Type1 点优化；
- 下游排队比峰值 `>= 0.8` 或下游饱和度峰值 `>= 0.85`：Type2 线优化。

峰值只负责证明“窗口内出现过问题”，不等价于“整个时段持续拥堵”。

## 3. Case A 为什么可以保留

目标侧采用有限数据代理：把同一诊断窗口内的路口级最大排队长度投影到用户点名方向，并仍使用该方向真实进口道库容计算排队代理比。下游侧不使用该代理，必须绑定真实接收进口道和真实转向排队。

坤顺路与奥体西路北进口左转的筛选证据为：

| 指标 | 数值 | 用途 |
|------|------|------|
| 饱和度峰值 | 约 1.35 | 触发目标问题判定 |
| 目标方向排队代理 | 163m / 356.63m = 0.4571 | 路口级最大排队投影，不触发溢流 |
| 目标转向真实均值 | 6.84m / 356.63m = 0.0192 | 审计保留，不作为演示主值 |
| 下游排队比峰值 | 约 0.06 | 证明下游仍有空间 |
| 下游饱和度峰值 | 约 0.33 | 证明下游承接压力较低 |

因此它表达的是“局部时段过饱和、路口存在较长排队、下游仍可承接”，适合讲解局部加绿逻辑；0.4571 仍低于 0.8，不能表述为已发生溢流。

界面主值显示目标方向排队代理比 0.4571，同时保留真实目标转向均值 6.84m 作为审计字段。下游承接状态始终使用真实接收进口道转向指标。

## 4. 当前限制

- 筛选覆盖多个周内典型日，运行页通常展示诊断工单所选典型日，日期范围不完全相同；
- 排队比展示以窗口平均排队长度计算，案例触发以饱和度或排队比峰值判断；
- 峰值对异常切片敏感，不能用于证明问题持续性；
- 绿灯利用率源表部分值可大于 1，当前按强度指标展示，不能直接解释为百分比；
- 案例用于逻辑演示，不应直接生成生产控制指令。

## 5. 数据丰富后的升级方向

当目标路口及其直接下游具备连续四周以上、工作日覆盖稳定、缺失率可控的同粒度数据后，升级为“峰值 + 持续性”双门槛：

- 增加 P95、时段均值和连续超阈切片数；
- 筛选与运行页统一日期范围和统计口径；
- 将“瞬时异常”“阶段性拥堵”“持续拥堵”分级展示；
- 正式典型案例优先选择多个工作日可重复出现的方向；
- 重新评估并版本化阈值，保留旧口径结果用于回归对照。

## 5.1 严格溢流型点优化筛选

如果演示命题明确要求“当前方向存在溢流风险、下游可承接”，则不能使用目标侧路口级排队代理，必须同时满足：

- 目标：同一 `inter_id + eight_direction + turn_dir_no` 的 `queue_len_avg / direction_storage >= 0.8`；
- 拓扑：按目标转向映射出口和直接下游接收进口；
- 下游：接收进口同转向的真实排队比峰值 `< 0.8`；
- 排序：先按目标排队比均值降序，再按峰值降序，优先选择较稳定而非单切片异常的案例。

2026-07-13 全库扫描得到 22 个严格候选。首选为花园东路与奥体中路路口西进口直行：目标库容 92.30m、排队峰值 100m、峰值比 1.0834、均值比 0.4003；直接下游崇华路与花园东路路口接收进口直行库容 288.64m、排队峰值 70.60m、峰值比 0.2446。该案例在排队维度上完整满足“本路口溢流、下游可承接”。

坤顺路与奥体西路北左不满足严格条件：旧嗅探值约 0.833 来自 `163m / 195.68m` 的路口聚合组合，而北进口真实库容为 356.63m；即使使用 163m 路口级最大排队代理，排队比也只有 0.4571，不能证明北左溢流。

## 6. 演示文案约束

允许使用：

- “晚高峰窗口内出现过饱和”；
- “局部时段供需失衡”；
- “下游仍有承接空间，可进行点优化演示”。

避免使用：

- “整个晚高峰持续严重排队”；
- “排队已经溢出”；
- “仅凭 0.03 排队比即可证明拥堵严重”。
