## 🎨 核心设计理念

本项目前端定位为**面向交通决策专家的决策支持中心（Decision Support Center）**，而非传统的地图信息看板。设计遵循以下三大原则：

1. **渐进式披露（Progressive Disclosure）**
   - 交通专家的思考链路是环环相扣的（理解 ➔ 定位 ➔ 验证 ➔ 诊断 ➔ 溯源 ➔ 策略 ➔ 方案 ➔ 反馈）。
   - UI 界面同样采用「流水线」式向下步进披露，每一步呈现当前最核心的数据与图表，右侧地图同步响应缩放和高亮，避免信息超载。
2. **三维立体化地网联动（GIS-UI Co-linking）**
   - 地图不再是静态背景，而是状态的一部分。从**路网微观（路口放电车流）**到**干线宏观（上下游波及路径）**，随着流水线的前进，地图自动进行俯仰角转换（2D/3D 视点转换）、范围聚焦、热力流向等动态渲染。
3. **专家级业务表达（Expert Domain Language）**
   - 采用「排队比」「饱和度」「绿灯利用率」「上游控流削峰」等专业指标看板。
   - 配时方案提供**双向时距图**和**相位结构图**，让专家一目了然方案的物理可行性。
