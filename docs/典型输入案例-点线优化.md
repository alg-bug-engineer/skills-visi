# 典型输入案例 · 点/线优化三类（交警视角）

> 最后更新：2026-07-12（Case A 改为北进口左转→礼耕下游可承接）  
> 数据来源：全库点线筛选 + PG 真源复核  
> 方法论：`docs/点线优化路口筛选分析.md`  
> Live fixture：`frontend/src/mock/cases/`（A 需按新 query 重采）

基于全库走廊配对筛选与指标复核，保留 **3 个典型路口**（原 Case C 因健康分支仅 2 幕、无法支撑线优化 demo，已剔除）。每例包含：**问题描述 + 处置经验 + 解法取向**，并收敛为**一句话 query**。

| 类型 | 含义 | 本批案例 |
|------|------|----------|
| **Type1 点优化** | 本路口有问题，分转向看下游仍有承接空间 → 可局部增绿 | **Case A**（北左→礼耕，下游 slack） |
| **Type2 线优化** | 本路口有问题且下游 blocked / 须走廊协调 → 截流或联动 | **Case B**（下游先堵）、**Case D**（北进口直行积压） |

**书写规范**：「下游」指**该转向的出口走廊**，不能与进口上游、其他转向的出口混写。口径见 `docs/点线优化路口筛选分析.md` §3。

## Case A · 点优化｜坤顺路×奥体西路（北进口左转）

| 字段 | 内容 |
|------|------|
| **配时调节对象** | **仅**坤顺路与奥体西路路口 (`011wwe28fty00001`) |
| **优化类型** | Type1 点优化（下游可承接 → 本路口局部加绿） |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | **北进口左转** → 东出口 → **坤顺路×礼耕路**（下游西进口接收） |
| **关键指标（PG 筛选口径）** | 目标北左 sat max≈1.35、有排队（q_avg max≈40.8）；下游礼耕西进口相对走廊间距 306m 溢流比≈0.14 → **slack** |
| **数据注意** | 北直往南下游「奥体西×解放东」排队/饱和不可用，**不再**作为 Case A 走廊 |
| **Live（2026-07-12）** | NLU 北向南+左转；下游礼耕。仅本 Case（目标 `011wwe28fty00001`）下游排队按接收进口 `queue_len_avg` 均值筛选（BUG-006）；其他路口仍用整路口 max。需再 live 重采验证 |

### 空间关系（上北下南）

```
              北 ↑ 安成街×奥体西路
  西 ← 无名道路 ──【坤顺路×奥体西路】──→ 东 坤顺路×礼耕路（北左下游，可承接）
              南 ↓ 奥体西路×解放东路（北直下游；数据空洞，非本 Case）
```

**一句话 query**：

```text
坤顺路与奥体西路路口，晚高峰十七点到十九点，北进口左转过饱和并有排队积压，东向下游坤顺路与礼耕路路口仍有承接空间，按点控经验在本路口对北进口左转做局部加绿优化。
```

## Case D · 线优化｜解放东路×奥体中路

| 字段 | 内容 |
|------|------|
| **协调主体** | 解放东路与奥体中路路口 (`011wwe294k300001`) |
| **优化类型** | Type2 — **北进口直行积压 + 防溢流协调** |
| **时段** | 晚高峰 16:00–19:00 |
| **核心流向** | 北进口直行 |
| **关键指标（live）** | 北左饱和 ~1.77、排队比 ~0.73 |
| **Live** | **`completed=True`** |

```
坤顺路×奥体中路 ──北进口(上游)──→ 【本路口】 ──南出口/北直──→ 往南
              南进口北行 ──北出口──→ 坤顺路×奥体中路（南向北下游）
```

- 坤顺路×奥体中路对**北进口是上游**，对**南进口北行才是下游**；不宜混写。

**一句话 query**：

```text
解放东路与奥体中路路口，晚高峰十六点到十九点，北进口直行积压严重，按线优化经验做防溢流和相位协调。
```
