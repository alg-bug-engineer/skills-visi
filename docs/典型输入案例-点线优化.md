> 最后更新：2026-07-13  
> 正式典型：**仅两例**（晚高峰点优化 + 晚高峰线优化）  
> Live fixture：`frontend/src/mock/cases/` · 校验副本：`data/live-validation/`  
> 方法论：`archive/docs/点线优化路口筛选分析.md`

| 类型 | 含义 | 正式案例 |
|------|------|----------|
| **Type1 点优化** | 本路口有问题，分转向看下游仍有承接空间 → 可局部增绿 | **Case A**：坤顺路×奥体西路 **北进口左转** → 礼耕路 |
| **Type2 线优化** | 本路口有问题且下游 blocked / 须走廊协调 → 截流或联动 | **Case B**：解放东路×奥体中路 **南进口直行** → 坤顺路×奥体中路 |

**已剔除**：原 Case B（二环东路×浆水泉西路）、旧 Case D「北进口直行」表述，以及健康分支 Case C。勿再作为默认演示输入。

**书写规范**：「下游」指**该转向的出口走廊**，不能与进口上游、其他转向的出口混写。口径见 `archive/docs/点线优化路口筛选分析.md` §3。

## Case A · 点优化｜坤顺路×奥体西路（北进口左转→礼耕）

| 字段 | 内容 |
|------|------|
| **配时调节对象** | **仅**坤顺路与奥体西路路口 (`011wwe28fty00001`) |
| **优化类型** | Type1 点优化（下游可承接 → 本路口局部加绿） |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | **北进口左转** → 东出口 → **坤顺路×礼耕路**（下游西进口接收） |
| **关键指标（PG 筛选口径）** | 目标北左过饱和且有排队；下游礼耕西进口相对走廊溢流比低 → **slack** |

### 空间关系（上北下南）

```
              北 ↑ 安成街×奥体西路
  西 ← 无名道路 ──【坤顺路×奥体西路】──→ 东 坤顺路×礼耕路（北左下游，可承接）
              南 ↓ 奥体西路×解放东路（北直下游；非本 Case）
```

**一句话 query**：

```text
坤顺路与奥体西路路口，晚高峰十七点到十九点，北进口左转过饱和并有排队积压，东向下游坤顺路与礼耕路路口仍有承接空间，按点控经验在本路口对北进口左转做局部加绿优化。
```

## Case B · 线优化｜解放东路×奥体中路（南进口直行→坤顺×奥体中）

| 字段 | 内容 |
|------|------|
| **协调主体** | 解放东路与奥体中路路口 (`011wwe294k300001`) |
| **优化类型** | Type2 — **南进口直行积压 + 下游承接不足 → 干线协调** |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | **南进口直行** → 北出口 → **坤顺路×奥体中路** |
| **策略取向** | 本路口不能简单加绿；向上游溯源并制定干线协调 |

### 空间关系（上北下南）

```
坤顺路×奥体中路 ←──北出口（南直下游）── 【解放东路×奥体中路】 ←──南进口直行──
                      （勿写成北进口直行；坤顺×奥体中对本路口北进口是上游）
```

**一句话 query**：

```text
解放东路与奥体中路路口，晚高峰十七点到十九点，南进口直行过饱和并有排队积压，向北下游坤顺路与奥体中路路口承接能力不足，本路口不能简单加绿，需要向上游溯源并制定干线协调策略。
```
