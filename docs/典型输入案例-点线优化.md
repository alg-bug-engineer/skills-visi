# 典型输入案例 · 点/线优化四类（交警视角）

> 落库时间：2026-07-09  
> 数据来源：全库点线筛选 `data/screening/point-line-latest/` + Top5 人工复核 `data/screening/top5-review-latest/`  
> 方法论：`docs/点线优化路口筛选分析.md`

基于全库走廊配对筛选与指标复核，选取 **4 个典型路口** 作为智能体主页/API 输入 Case。每例包含：**问题描述 + 处置经验 + 解法取向**，并收敛为**一句话 query**（交警口述风格）。

| 类型 | 含义 | 本批案例 |
|------|------|----------|
| **Type1 点优化** | 本路口有问题，直接下游仍有承接空间 → 可局部增绿 | Case A |
| **Type2 线优化** | 本路口有问题且下游 blocked → 上游截流/走廊协调 | Case B、C、D |

---

## Case A · 点优化｜坤顺路×奥体西路

| 字段 | 内容 |
|------|------|
| **目标路口** | 坤顺路与奥体西路路口 (`011wwe28fty00001`) |
| **优化类型** | Type1 点优化 |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | 东进口直行、北进口直行/左转等多转向 |
| **关键指标** | 晚高峰路口饱和 max≈1.95；东直行饱和≈1.95；溢流比峰值≈0.49（未达 0.8 但饱和触发） |
| **下游承接** | 安成街×奥体西路、坤顺路×礼耕路等方向余量尚可（筛选 TYPE1_POINT） |

**问题**：晚高峰东进口直行及多个转向饱和度接近 2.0，车辆在路口积压、绿灯利用率高，放行能力不足。

**经验**：类似奥体西路片区节点，下游安成街、礼耕路方向仍能吃下流量，不宜盲目全线加压，适合「本路口加绿、下游有地儿停」的点控做法。

**解法**：在确认下游不堵的前提下，对东直行等高饱和转向做**局部配时优化（增绿/重分配）**。

**一句话 query（推荐输入）**：

```text
坤顺路与奥体西路路口，晚高峰十七点到十九点，东进口直行和北进口多个转向饱和度都接近两、车辆在路口积压放行不出去，但下游安成街和礼耕路方向还能吃下流量，按以往点控经验在下游不堵的前提下给东直行等高饱和转向做局部加绿配时优化。
```

## Case B · 线优化｜二环东路×浆水泉西路

| 字段 | 内容 |
|------|------|
| **目标路口** | 二环东路与浆水泉西路路口 (`011wwe0rynv00001`) |
| **直接下游** | 二环东路出口与二环东路辅路路口 (`011wwe0rvxj00001`) |
| **优化类型** | Type2 线优化 |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | 北进口直行 |
| **关键指标** | 目标北直行饱和 max≈0.94；下游接收方向饱和 max≈2.12 |
| **走廊分型** | TYPE2_LINE（目标过饱和 + 下游 blocked） |

**问题**：晚高峰北进口直行过饱和，排队向上游顶，本路口通行与放行压力大。

**经验**：下游二环东路辅路路口早已堵死、饱和超 2.0，属于「下游先堵、上游再加绿只会外溢」的典型线控场景。

**解法**：**不宜本路口单纯加绿**；采取上游截流、与下游辅路路口**协调配时**及防溢流相位。

**一句话 query（推荐输入）**：

```text
二环东路与浆水泉西路路口，晚高峰十七点到十九点，北进口直行过饱和排队往上顶，下游二环东路辅路路口早就堵死饱和度超两了，本路口不能再简单加绿，按线控经验做上游截流并和下游辅路路口协调配时防溢流。
```

## Case C · 线优化｜旅游路×荆山东路

| 字段 | 内容 |
|------|------|
| **目标路口** | 旅游路与荆山东路路口 (`011wwe22jsg00001`) |
| **关联节点** | 旅游路与浆水泉路路口 (`011wwe22mcj00001`) — 双向走廊对 |
| **优化类型** | Type2 线优化 |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | 西进口直行、东进口直行（双向） |
| **关键指标** | 西直行饱和≈1.25；下游浆水泉路方向饱和≈1.28；反向东直行亦 TYPE2 |
| **走廊分型** | TYPE2_LINE（双向互堵） |

**问题**：晚高峰西进口直行、东进口直行双向饱和度均超 1.0，车辆积压在路口，走廊通行不畅。

**经验**：下游旅游路×浆水泉路路口同样过饱和，且与本案构成**双向线优化走廊**，单点猛加绿会加剧对向/下游拥堵。

**解法**：按**旅游路走廊整体**做协调（绿波/防溢流/上游节奏控制），与浆水泉路路口成对处理。

**一句话 query（推荐输入）**：

```text
旅游路与荆山东路路口，晚高峰十七点到十九点，西进口直行和东进口直行双向饱和度都超一、车放不出去，下游旅游路与浆水泉路路口同样过饱和，整条旅游路走廊要一起协调，按线控做法别单点猛加绿。
```

## Case D · 线优化｜解放东路×奥体中路

| 字段 | 内容 |
|------|------|
| **目标路口** | 解放东路与奥体中路路口 (`011wwe294k300001`) |
| **直接下游** | 坤顺路与奥体中路路口 (`011wwe294sq00001`) — 南向北直行走廊 |
| **优化类型** | Type2 线优化 |
| **时段** | 早高峰 07:30–08:50 |
| **核心流向** | 北进口左转（极端饱和）、南进口直行（走廊） |
| **关键指标** | 北左转饱和 max≈2.68；南直行→下游饱和≈1.21、溢流≈0.36 |
| **走廊分型** | TYPE2_LINE（上下游同堵） |

**问题**：早高峰北进口左转饱和度极端，南向北直行亦顶到下游坤顺路×奥体中路，上下游同步拥堵。

**经验**：南向北走廊为典型「本路口 + 下游一起堵」，与早期仅强调「下游有空间」的第一类案例不同，应以**防外溢、走廊协调**为先，不能单点加绿。

**解法**：**线优化** — 走廊协调 + 防溢流配时；北左转能力/相位与南向北走廊统筹。

**一句话 query（推荐输入）**：

```text
解放东路与奥体中路路口，早高峰七点半到八点五十，北进口左转饱和度极端、南向北直行也顶到下游坤顺路与奥体中路路口，上下游一起堵，按线优化经验做走廊协调和防溢流配时，优先避免往南继续外溢。
```
