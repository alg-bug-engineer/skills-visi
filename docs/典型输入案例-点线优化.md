# 典型输入案例 · 点/线优化三类（交警视角）

> 最后更新：2026-07-10（剔除 Case C；A/B/D live 重采）  
> 数据来源：全库点线筛选 + Top5 人工复核  
> 方法论：`docs/点线优化路口筛选分析.md`  
> Live fixture：`frontend/src/mock/cases/`（2026-07-10 重采）

基于全库走廊配对筛选与指标复核，保留 **3 个典型路口**（原 Case C 因健康分支仅 2 幕、无法支撑线优化 demo，已剔除）。每例包含：**问题描述 + 处置经验 + 解法取向**，并收敛为**一句话 query**。

| 类型 | 含义 | 本批案例 |
|------|------|----------|
| **Type1 点优化** | 本路口有问题，分转向看下游仍有承接空间 → 可局部增绿 | **Case A** |
| **Type2 线优化** | 本路口有问题且下游 blocked / 须走廊协调 → 截流或联动 | **Case B**（下游先堵）、**Case D**（北进口上游压力 + 南向北走廊） |

**书写规范**：「下游」指**该转向的出口走廊**，不能与进口上游、其他转向的出口混写。口径见 `docs/点线优化路口筛选分析.md` §3。

## Case A · 点优化｜坤顺路×奥体西路

| 字段 | 内容 |
|------|------|
| **配时调节对象** | **仅**坤顺路与奥体西路路口 (`011wwe28fty00001`) |
| **优化类型** | Type1 点优化 |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | **北进口**（直行/左转同相位，局部优化北进口相位） |
| **关键指标（live）** | 北直 ~1.54、北左 ~1.24；排队比 ~0.83 |
| **Live** | `completed=False`（优化周期超 90s 护栏时） |

### 空间关系（上北下南）

```
              北 ↑ 安成街×奥体西路
  西 ← 无名道路 ──【坤顺路×奥体西路】── 礼耕路 → 东
              南 ↓ 奥体西路×解放东路（北进口直行主下游）
```

**一句话 query**：

```text
坤顺路与奥体西路路口，晚高峰十七点到十九点，北进口过饱和、路口积压，按点控经验在本路口做北进口相位局部优化。
```

## Case B · 线优化｜二环东路×浆水泉西路

| 字段 | 内容 |
|------|------|
| **协调主体** | 二环东路与浆水泉西路路口 (`011wwe0rynv00001`) |
| **优化类型** | Type2 — **下游先堵型** |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | 北进口直行 → 南出口 → 辅路路口 |
| **关键指标（live）** | 目标 0.80；下游接收 1.46、`blocked=true` |
| **Live** | **`completed=True`** |

```
荆山路×二环东路 ──北进口──→ 【本路口】 ──南出口──→ 二环东路辅路路口（下游堵）
```

**一句话 query**：

```text
二环东路与浆水泉西路路口，晚高峰十七点到十九点，北进口直行排队往上顶，下游二环东路辅路路口饱和度高早就承接不住，本路口不能再简单加绿，按线控经验做上游截流并和下游辅路路口协调配时防溢流。
```

## Case D · 线优化｜解放东路×奥体中路

| 字段 | 内容 |
|------|------|
| **协调主体** | 解放东路与奥体中路路口 (`011wwe294k300001`) |
| **优化类型** | Type2 — **北进口上游压力 + 南向北走廊** |
| **时段** | 早高峰 07:30–08:50 |
| **核心流向** | 北进口直/左（主）；南进口北行单独走廊 |
| **关键指标（live）** | 北直 1.86、北左 1.66；南直 0.55 |
| **Live** | `completed=False`（184s > 180s） |

```
坤顺路×奥体中路 ──北进口(上游)──→ 【本路口】 ──南出口/北直──→ 往南
              南进口北行 ──北出口──→ 坤顺路×奥体中路（南向北下游）
```

- 坤顺路×奥体中路对**北进口是上游**，对**南进口北行才是下游**；不宜混写。

**一句话 query**：

```text
解放东路与奥体中路路口，早高峰七点半到八点五十，北进口直行和左转过饱和、北侧坤顺路与奥体中路路口来车压力大，本路口积压严重，按线优化经验做防溢流和相位协调，南向北直行另须盯下游坤顺路与奥体中路路口别往南顶回溢流。
```
