# 典型输入案例 · 点/线优化（交警视角）

> 最后更新：2026-07-13  
> 演示案例：严格点优化 Case A + 线优化 Case B  
> Live fixture：`frontend/src/mock/cases/` · 校验副本：`data/live-validation/`  
> 方法论：`archive/docs/点线优化路口筛选分析.md`

| 类型 | 含义 | 正式案例 |
|------|------|----------|
| **Type1 点优化** | 目标真实转向排队比峰值 ≥0.8，且下游真实接收转向可承接 | **Case A**：花园东路×奥体中路西进口直行 → 崇华路×花园东路 |
| **Type2 线优化** | 本路口峰值异常且下游 blocked / 须走廊协调 → 截流或联动 | **Case B**：解放东路×奥体中路 **南进口直行** → 坤顺路×奥体中路 |

受真实数据覆盖限制，当前采用窗口峰值逻辑作为演示口径。案例用于讲解决策链，不代表生产级持续拥堵认定；详见 [`峰值口径演示说明.md`](./峰值口径演示说明.md)。

**书写规范**：「下游」指**该转向的出口走廊**，不能与进口上游、其他转向的出口混写。口径见 `archive/docs/点线优化路口筛选分析.md` §3。

## 历史 Case A（已下架）· 坤顺路×奥体西路（北进口左转→礼耕）

下架原因：北左真实转向排队比及路口级最大排队代理比均未达到 0.8，不能支撑“当前方向有溢流风险”的严格点优化命题。

| 字段 | 内容 |
|------|------|
| **配时调节对象** | **仅**坤顺路与奥体西路路口 (`011wwe28fty00001`) |
| **优化类型** | Type1 点优化（下游可承接 → 本路口局部加绿） |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | **北进口左转** → 东出口 → **坤顺路×礼耕路**（下游西进口接收） |
| **关键指标（PG 筛选口径）** | 目标北左过饱和且有排队；下游礼耕西进口相对走廊溢流比低 → **slack** |

### 空间关系（上北下南）

```
              北 ↑ 安成街×奥体西路
  西 ← 无名道路 ──【坤顺路×奥体西路】──→ 东 坤顺路×礼耕路（北左下游，可承接）
              南 ↓ 奥体西路×解放东路（北直下游；非本 Case）
```

**一句话 query**：

```text
坤顺路与奥体西路路口，晚高峰十七点到十九点，北进口左转局部时段过饱和，东向下游坤顺路与礼耕路路口仍有承接空间，按峰值口径在本路口对北进口左转做局部加绿优化。
```

## Case B · 线优化｜解放东路×奥体中路（南进口直行→坤顺×奥体中）

该案例同样按目标/下游窗口峰值关系讲解线优化，不用于证明整个晚高峰持续拥堵。

| 字段 | 内容 |
|------|------|
| **协调主体** | 解放东路与奥体中路路口 (`011wwe294k300001`) |
| **优化类型** | Type2 — **南进口直行局部时段异常 + 下游承接不足 → 干线协调** |
| **时段** | 晚高峰 17:00–19:00 |
| **核心流向** | **南进口直行** → 北出口 → **坤顺路×奥体中路** |
| **策略取向** | 本路口不能简单加绿；向上游溯源并制定干线协调 |

### 空间关系（上北下南）

```
坤顺路×奥体中路 ←──北出口（南直下游）── 【解放东路×奥体中路】 ←──南进口直行──
                      （勿写成北进口直行；坤顺×奥体中对本路口北进口是上游）
```

**一句话 query**：

```text
解放东路与奥体中路路口，晚高峰十七点到十九点，南进口直行局部时段过饱和，向北下游坤顺路与奥体中路路口承接能力不足，按峰值口径制定干线协调策略。
```
