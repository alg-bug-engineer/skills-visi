# 历史文档归档

本目录存放**已落地或过期**的需求、开发计划与分析笔记，便于根目录只保留现行工作项。

## 归档规则

| 类别 | 规则 |
|------|------|
| `needs/`、`plans/` | 编号 **1–28** 已迁入此处；**29+** 仍在仓库根目录对应目录 |
| `docs/` | 历史进度快照与过期分析笔记 |
| `bugs/` | **不归档**，缺陷台账仍在根目录 `bugs/` |

## 目录

```
archive/
├── needs/    # 历史需求 1–28
├── plans/    # 历史开发计划 1–28
└── docs/     # 项目进度快照、点线筛选分析、上下游关系统计表等
```

查阅时注意：归档文档内部的相对路径（如 `needs/2`、`docs/项目进度.md`）可能仍写旧位置，以本目录实际文件为准。

现行入口见仓库根目录 [`README.md`](../README.md) 与 [`docs/部署指南.md`](../docs/部署指南.md)。
