# 需求 2：生产化优化

## 需求概述

在需求 1（初始化后端）五 Skill 流水线骨架基础上，去除 demo 化实现，对齐 `references/intersection/` 生产技能口径，并以 `docs/剧本.md` 九幕叙事为验收标准，完成诊断数据真源、方案护栏、剧本字段与反馈闭环。

## 需求条目

1. 遵循 `docs/rule.md` 第 14–18 条：**禁止 demo 形式开发**，Skill 须满足生产约束与数据真源要求，剧本字段为验收标准
2. 去除生产路径上对 `demo_metrics` / `demo_topology` 的静默 fallback；无 PG/注入数据时返回 `available: false` + `reason`
3. 方案生成对齐 `references/intersection/plan-generation`：优化器 + `validate_plan_guardrails`（最小绿、最大周期、黄灯全红、行人过街、回滚条件）
4. 诊断数据接入 PG/MySQL（拷贝适配 `references/intersection/scene-cognition` 加载逻辑，禁止 import references）
5. 剧本第一至八幕所需结构化输出字段在 `artifacts` 中可逐项映射；第九幕反馈沉淀 Skill + API
6. 详细开发计划见 `plans/2-生产化优化.md`；开发前阅读 `bugs/` 记录

## 与需求 1 的边界

| 需求 1（已完成） | 需求 2（本需求） |
|-----------------|-----------------|
| Skill Runtime、五 Skill 骨架、API、mock LLM 端到端 | 生产数据、护栏、完整输出 schema |

## 反思：与 `references/intersection` 生产技能差异

`references/intersection` 共五个生产 Skill，与当前 `skills/` 映射如下：

| references 生产 Skill | 当前 skills | 核心 Gap |
|----------------------|-------------|----------|
| `scene-cognition` | `data-analysis-diagnosis` | 缺 PG 检查单全量加载（渠化、最小绿、转向流量等 15+ 项）；仅用 demo 指标 |
| `problem-diagnosis` | `cause-analysis` | 缺六维成因评分、检查单驱动的 `cause_scores`；案例非结构化 |
| `control-strategy` | `strategy-generation` | 缺策略包与优化引擎的 `strategy_instruction` 契约；无控制范围输出 |
| `plan-generation` | `plan-generation` | **最大 Gap**：无 `generate_timing_plan`、无 SLSQP 优化、无 `validate_plan_guardrails` |
| `evaluation-feedback` | （无） | 整 Skill 缺失；无 KPI 对比与案例沉淀 |

### plan-generation 生产约束（必须补齐）

参考 `references/intersection/plan-generation/references/rules.md`：

- 输入：`inter_id`、`target_periods`、`phasePlanOfTimeList`
- 优化：联合周期 + 绿信比（与原工程 `signal_optimization_engine` 一致）
- 护栏：周期 ≤ `max_cycle_s`；阶段绿灯 ≥ `minGreenTime`；必填回滚条件
- 数据不足：结构化错误，禁止编造阶段

当前 `build_candidates.py` 硬编码 `cycle_sec: 120`、`绿灯_sec: 28/35/32`，不满足任何一条。

### scene-cognition 数据真源（必须补齐）

参考 `checklist_rules.md`：最小绿来自 `dws_turn_min_green_5min_mm`，配时来自 `dwd_ctl_inter_plan_stage_timing`，流量/排队来自 DWS 5min 表。当前 `demo_metrics.py` 违反 `rule.md` 第 16 条。

## 阶段 E（P0 续）：数据嗅探、路口匹配、确定性评分、时间窗（本分支）

### E1. PG 配时数据嗅探

- 脚本 `app/data/pg_signal_sniffer.py`：扫描 `dwd_ctl_inter_plan_cfg` + `dwd_ctl_inter_plan_stage_timing`
- 输出 `data/pg_signal_coverage.json`（含 `inter_id`、`inter_name`、`stage_cnt`），供联调/测试选用
- 不绑定剧本示例路口

### E2. 路口口语化匹配（LLM + 确定性排序）

- `app/data/intersection_matcher.py`：名称变体（A与B / B与A）、PG 多候选检索、置信度评分
- 意图 Skill 输出 `intersection_name_candidates`，LLM 抽取口语化路名后与 PG 候选对齐
- `enrich_ticket` 接入 matcher，记录 `match_confidence`、`match_candidates`

### E3. 诊断时间窗过滤

- `parse_time_step_range`：从 `time_range` 解析 `step_index` 区间
- `_assemble_task_from_raw` 聚合前按 step 过滤 DWS 动态表行，避免全天极值污染

### E4. 成因确定性评分 `cause_scores`

- `skills/cause-analysis/scripts/score_cause_dimensions.py`
- 六维：`demand/supply/control/order/event/coordination`
- 对齐 `diagnosis_checklist.yaml` + `thresholds.yaml`，输出 `cause_scores`、`issue_flags`

### E5. 策略确定性评分 + `strategy_instruction`

- `skills/strategy-generation/scripts/build_strategy_profile.py`
- 基于 `cause_scores` + 诊断输出 `strategy_package` 评分、`strategy_instruction`（优化器契约）

### E6. 测试

| 用例 | 断言 |
|------|------|
| `test_intersection_matcher_reversed` | B与A 匹配 A与B 路口 |
| `test_step_window_filters_metrics` | 时间窗外数据不参与聚合 |
| `test_cause_scores_dimensions` | 六维分数 0–1 |
| `test_strategy_instruction_contract` | 含 target_saturation/rollback |
