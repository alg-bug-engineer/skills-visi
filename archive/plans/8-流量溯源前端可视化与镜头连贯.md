# 计划8 · 流量溯源前端可视化与镜头连贯运镜

对应需求：`needs/8-流量溯源前端可视化与镜头连贯.md`。分支：当前 `feature/frontend-presentation-optimization`（用户指定当前分支开发，人工确认前不合入 main）。

## 原则

- 呈现/取数逻辑 **严格对齐** `references/流量溯源`（= `references/frontend-v2`），**仅改配色**。
- 禁止前端造数（rule 19）：只消费后端真实 `path`/坐标/`share_pct`；缺则降级，不合成。
- 参考为只读快照，**借鉴逻辑、不 import**（rule 11）；把 Vue `MapStage` 的运镜/图层调度提炼进本项目纯 TS `MapController`。

## 现状诊断（闪烁根因）

| # | 根因 | 位置 |
|---|------|------|
| 1 | `currentAct` 与 `diagnosis` 两个 watch 各调一次 `applyScene` → 流式时二次重放镜头 + `clear()` | `frontend/src/map/AMapProvider.vue` |
| 2 | `applyScene` 每次开头 `this.clear()` 后同步重绘 → 覆盖物闪现 | `MapController.applyScene` |
| 3 | `drillToIntersection` 步进 `[14,16.2,17.5]` **未对当前 zoom 取 max** → 已在 16 时进车道(17)先飞到 14（缩小再放大） | `frontend/src/map/amapUtils.ts` |
| 4 | 干线幕 `clampZoomUp` 锁高 zoom，抬升到 17 走的是硬 `setZoomAndCenter` | `MapController.applyScene` `trace/corridor` 分支 |
| 5 | 每幕 `setPitch` 突变 | `MapController.applyScene` |

参考 `frontend-v2` 的解法：每步 zoom `clampZoomUp = max(target, map.getZoom())`（单调不回退）；`withProgrammatic` 包裹程序化运镜；`userInteracted` 手动干预后不强拉；`cameraNearTarget` 就近跳过；干线抬升用单次平滑 `flyTo`。

## 架构

```
frontend/src/map/
├─ traceParticles.ts   (新) 纯函数：interpolatePath/sampleAlongPath/approxPathLength/particleDurationFor  [移植参考]
├─ traceLayer.ts       (新) TraceLayer 类：revealEdge/revealNode/renderDownstreamTraces/particles  [移植参考 UpstreamTraceLayer, 仅配色改]
├─ traceLabels.ts      (新) 纯函数：coverageNodeStyle/buildUpstreamLabelHtml/formatFeed  [移植参考 upstreamCorrelateLabels]
├─ amapUtils.ts        (改) drillToIntersection 每步 clamp≥当前 zoom；新增 smoothPullback（受控降 zoom 动画）
├─ MapController.ts     (改) 用 TraceLayer 绘溯源；镜头连贯化；clear→差量/淡出；sceneToken 再入保护
└─ AMapProvider.vue     (改) 合并双 watch，去抖；diagnosis 补齐仅补绘不重放镜头；userInteracted 监听
```

配色（本项目主题变量，唯一允许改动项）：上游 glow `#f5a623`/core `#ffcf7a`；下游 glow `#0ea5e9`/core `#38bdf8`；目标红 `#ff5050`；治理绿 `#6dffb5`。与参考同色系，落到本项目 `theme`。

## 阶段拆解

### P1 需求与计划（本文件） ✅

### P2 纯函数工具（含单测先行）
- `traceParticles.ts`：移植 `interpolatePath/sampleAlongPath/approxPathLength/particleDurationFor`。
- `traceLabels.ts`：移植 `coverageNodeStyle`、占比标签 HTML、`formatFeedDirection`、`MIN_PATH_COVERAGE`。
- `amapUtils.ts`：`drillSteps(current,target)` 纯函数返回单调不回退步序；`clampZoomUp` 保留。
- 单测（落 `frontend/tests/unit/`，匹配既有 vitest include）：`trace-particles.test.ts`、`camera.test.ts`、`trace-labels.test.ts`（drillSteps 单调性、端点插值、时长夹取、占比样式）。

### P3 溯源渲染层 `traceLayer.ts`
- 移植参考 `UpstreamTraceLayer`：`revealEdge`（glow×3 宽 + 亮核 + showDir + `addParticles` rAF）、`revealNode`（`coverageNodeStyle` 缩放 + 角色配色）、`renderDownstreamTraces`（青蓝单链 + 节点 + 标签）、`renderUpstreamTraces`（琥珀，从 `entry_traces` 映射：path/upstream_lng/lat/dominant share_pct/label）。
- `reset/dispose` 释放覆盖物 + 停 rAF；`overlays()` 供 `setFitView` 收束。
- 仅配色替换，其余（线宽随占比、粒子定速、zIndex 分层、幂等 id）保持参考口径。

### P4 镜头连贯（`MapController` + `amapUtils`）
- `drillToIntersection`：`for z of drillSteps(current,target)` 单调放大，单次 `flyTo` 每段；城市(11)→路口(16)→车道(18) 全程只增。
- 车道级：续接当前镜头 `flyTo(clampZoomUp(current,18),800)`，不回退。
- 干线抬升：新增 `smoothPullback(center, 17, dur≥800)`——`setStatus({animateEnable:true}) + setZoomAndCenter(17,center,false,dur)` 单次动画，允许从 18 降到 17；不经 `clampZoomUp`。
- `pitch` 用 `flyTo` 前统一设一次或缓变，避免逐幕突变。
- `applyScene`：先运镜到位（`await`），`sceneToken` 校验后再绘覆盖物；换幕用 `traceLayer.reset()` + 主覆盖物淡出，而非无脑 `clear()` 硬闪。

### P5 去抖再入（`AMapProvider.vue`）
- 合并 `currentAct` 与 `diagnosis` 两 watch：`currentAct` 变化才运镜；`diagnosis` 到达且仍是同一幕时，调 `applyScene(..., replayCamera=false)` 仅补绘覆盖物/指标。
- `MapController.applyScene(scene, resp, {showMetrics, replayCamera})`：`replayCamera=false` 时跳过镜头段。
- 监听 `map` `dragend/zoomend`（非程序化）置 `userInteracted`，后续 `focus*` 跳过强拉。

### P6 mock 数据合规校验（后端按需补 + 重采）
- 校验 fixture：`entry_traces[].path/upstream_lng/lat/upstream_movements[].share_pct`、`turn_traces[].path/lon/lat/share_pct/capacity/movement/name` 是否满足 P3 渲染。
- **结论**：现有 `frontend/src/mock/run_1_fixture.json`（需求7 已由后端 `672859c` 补齐真实几何）**已满足** P3 全部消费字段——上游 `entry_traces[0].path`（9 点）+ `upstream_lng/lat` + `upstream_movements[0].share_pct=71.63`；下游 `turn_traces[].path/lon/lat/capacity/movement/name`（右/左转 `share_pct=null` 为真实缺占比 → 前端显示「拓扑」）。**本次无需改后端、无需重采**。
- 若后续新增字段需求：改 `app/data/pg_adapters.py` / `app/trace/flow_trace.py` 补真实字段，再 `.venv/bin/python scripts/capture_frontend_mock.py`（优先 `--from-log`）重采。无真实数据字段一律 `available:false`/`null`，前端降级「暂无数据」/「拓扑」，严禁前端造数。

### P7 前端接线与验证
- `MapController` 溯源分支切到 `TraceLayer`；`AMapProvider` 去抖接线。
- `npm run build`（tsc + vite）通过；`npm run test`（vitest）通过。
- `scripts/capture_frontend_mock.py` 若重采则同步；`VITE_MOCK=1` 启动，截图核对溯源呈现与镜头连贯（无闪烁）。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 参考为 Vue `MapStage`，本项目为纯 TS `MapController`，运镜状态机差异 | 仅提炼「单调 zoom + 单次平滑 + 再入保护 + userInteracted」核心，不照搬 Vue 生命周期 |
| 去抖后流式补绘时机不当导致溯源不显 | `applyScene(replayCamera=false)` 保留覆盖物补绘；`sceneToken` 幂等 |
| 后端字段不足需改接口 → 影响既有九幕 | 仅新增字段，保留既有契约；先跑后端单测再重采 fixture |
| 高德动画时长与 rAF 粒子叠加卡顿 | 粒子数/幂等 id 对齐参考；镜头动画期间粒子照常（参考同款） |
