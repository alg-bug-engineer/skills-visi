## 风险与缓解

| 风险 | 缓解 |
|------|------|
| `flow_correlate.trace_type` 经验性反转，误判来向/去向 | 几何定方向（entrance=上游/exit=下游），占比按 cor_inter_id 就近匹配 |
| 目标路口无请求日类型聚合 | 回退最新月任意日类型（仍真实），仍无则占比 null |
| 下游相邻路口无动态指标 | profile 缺省容错，占比/几何照常；指标 `null` 不伪造 |
| link 无 geom / 无邻接 | 该节点不产出；`available:false`，前端降级 |
| 破坏既有 e2e/单测 | 保留契约字段与 `data-testid`；先跑后端单测再重采 |
