## 二、R1 实现拆解

### 步骤 1：抽取演示节奏配置

新增 `frontend/src/config/demoPacing.ts`：

```ts
export const DEMO_TYPING_MS = Number(import.meta.env.VITE_DEMO_TYPING_MS ?? 28)
export const DEMO_ACT_DWELL_FIRST_MS = Number(import.meta.env.VITE_DEMO_ACT_DWELL_FIRST_MS ?? 750)
export const DEMO_ACT_DWELL_AFTER_MS = Number(import.meta.env.VITE_DEMO_ACT_DWELL_AFTER_MS ?? 2000)

export function actDwellMs(actIndex: number, instant: boolean): number {
  if (instant) return 0
  return actIndex <= 0 ? DEMO_ACT_DWELL_FIRST_MS : DEMO_ACT_DWELL_AFTER_MS
}
```

- `frontend/.env.example` 增加上述三个变量说明。
- `useTyping` 调用处传入 `speed: DEMO_TYPING_MS`（`ProcessPanel.vue`）。

### 步骤 2：ProcessPanel 使用 `actDwellMs`

替换固定 `750` 的 `setTimeout`。

## 七、风险

1. **旁白缓存与响应更新**：流式中途 `narrationFor` 随 snapshot 变化时，应在 `onDone` 一刻冻结，避免后验改字。
2. **折叠条与正文重复**：保留 `summaryFor` 仅用于折叠条时，展开态勿再重复同一结论。
3. **e2e 时长**：R1 增加总时长约 10–15s，需调大 `timeout` 若用例边界失败。
