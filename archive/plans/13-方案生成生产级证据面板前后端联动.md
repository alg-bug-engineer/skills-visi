# 方案生成生产级证据面板前后端联动 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将方案生成从“可信配时结果”升级为“生产级可审计证据面板”，后端输出真实现状/优化/方向/强度契约，前端用真实重采 fixture 在 `VITE_MOCK=1` 下回放调试。

**Architecture:** 后端在方案生成阶段构建统一 `timing` 证据契约，严禁前端补数；前端新增证据面板组件，只消费后端真实字段并在缺失时降级提示。验证链路固定为后端真实运行重采 `run_1_fixture.json`，再用 `VITE_MOCK=1` 调试前端。

**Tech Stack:** Python/FastAPI/pytest, Vue 3/Pinia/Vite/Vitest/Playwright, PG-backed traffic data, `signal_optimization_engine`.

---

关联需求：`needs/13-方案生成生产级证据面板前后端联动.md`

- [ ] **Step 1: Add a pure evidence builder**

Add a helper near `_normalize_optimizer_stages`:

```python
def _build_timing_evidence(
    *,
    signal: dict[str, Any],
    request: dict[str, Any],
    cycle_s: int,
    timing_list: list[dict[str, Any]],
    meta: dict[str, Any],
) -> dict[str, Any]:
    current_cycle = signal.get("current_cycle_s")
    request_stages = ((request.get("phasePlanOfTimeList") or [{}])[0].get("phaseStageInfoList") or [])
    request_by_id = {
        str(s.get("phaseStageId") or s.get("phase_stage_id")): s
        for s in request_stages
        if isinstance(s, dict)
    }
    stages = []
    missing_fields: list[str] = []
    for optimized in timing_list:
        stage_id = str(optimized.get("phase_stage_id") or "")
        source = request_by_id.get(stage_id, {})
        current = source.get("currentTiming") or {}
        movements = source.get("phaseDirInfoDTOList") or []
        if not current:
            missing_fields.append(f"phase_stage_timing_list[{stage_id}].current_timing")
        if not movements:
            missing_fields.append(f"phase_stage_timing_list[{stage_id}].movements")
        current_green = current.get("greenSec")
        current_yellow = current.get("yellowSec")
        current_all_red = current.get("allRedSec")
        optimized_green = optimized.get("green_time_s")
        optimized_yellow = optimized.get("yellow_time_s")
        optimized_all_red = optimized.get("all_red_time_s")
        stages.append({
            **optimized,
            "current_timing": {
                "green_time_s": current_green,
                "yellow_time_s": current_yellow,
                "all_red_time_s": current_all_red,
                "stage_total_s": current.get("stageTotalSec"),
            },
            "optimized_timing": {
                "green_time_s": optimized_green,
                "yellow_time_s": optimized_yellow,
                "all_red_time_s": optimized_all_red,
                "stage_total_s": (
                    optimized_green + optimized_yellow + optimized_all_red
                    if None not in (optimized_green, optimized_yellow, optimized_all_red)
                    else None
                ),
            },
            "green_delta_s": (
                optimized_green - current_green
                if None not in (optimized_green, current_green)
                else None
            ),
            "movements": [_normalize_movement_evidence(item) for item in movements],
        })
    if current_cycle is None:
        missing_fields.append("timing.current_cycle_s")
    direction_list = meta.get("direction_intensity_list")
    if not direction_list:
        missing_fields.append("timing.meta.direction_intensity_list")
    return {
        "available": not missing_fields,
        "reason": None if not missing_fields else "方案证据字段不完整，无法生产级展示",
        "missing_fields": missing_fields,
        "current_cycle_s": current_cycle,
        "cycle_s": cycle_s,
        "cycle_delta_s": cycle_s - current_cycle if current_cycle is not None else None,
        "phase_stage_timing_list": stages,
        "meta": _build_optimization_meta(meta),
    }
```

Add `_normalize_movement_evidence` and `_build_optimization_meta` as small pure helpers. They must copy real values and set `flow_available` from source; they must not invent flow or direction values.
